Normalize → Cite → Dry-run → Approve → Commit.

  1. Normalize — glossary + typo map fix sallery, EMP42, INV2041, 03/04 dates.
  2. Cite — top-5 policy chunks; every claim gets [doc_id:chunk].
  3. Dry-run — tools run read-only. Diff shown, nothing moves.
  4. Approve — human verdict via console, Slack, or WhatsApp. 15-min expiry.
  5. Commit — writes once with an idempotency key. Audit + trace saved.

Controls your auditors will ask about.

  • Zero unapproved commits — enforced in Python, not in prompts. No prompt can override it.
  • PII redaction — PAN, Aadhaar, bank and account numbers scrubbed before any log or trace; ingest can mask them at load.
  • Signed approvals — HMAC links expire in 15 minutes; every commit carries an idempotency key.
  • Durable jobs — Temporal workflows with retries, heartbeats, cancel, and content-addressed dedupe.
  • Full replay — any run_id replays from checkpoint; every approval exports to audit CSV.
