Normalize → Cite → Dry-run → Approve → Commit.

  1. Normalize — glossary + typo map fix sallery, EMP42, INV2041, 03/04 dates.
  2. Cite — top-5 policy chunks; every policy claim gets [doc_id:chunk].
  3. Dry-run — payroll_lookup / vendor_recon / slip_parse run read-only. Diff shown.
  4. Approve — human verdict via UI, Slack, or WhatsApp. Expires in 15 min.
  5. Commit — vendor_commit writes once with an idempotency key. Audit + trace saved.
