# ESI-2026 [esi]

- Employee ESI: `esi_employee = ESI_EMP_RATE * ESI_WAGE_BASE`. ESI_EMP_RATE is configurable. [esi:01]
- Employer ESI: `esi_employer = ESI_ER_RATE * ESI_WAGE_BASE`. ESI_ER_RATE is configurable. [esi:02]
- Eligibility gate: applies only if `monthly ESI_WAGE_BASE <= ESI_WAGE_CEIL`. ESI_WAGE_CEIL is configurable. [esi:03]
- ESI wage base: `ESI_WAGE_BASE = gross minus excluded components`. Exclusion list is configurable. [esi:04]
- Mid-month ceiling cross: once wage exceeds ceiling, stop ESI that month per tenant rule. Rule is configurable. [esi:05]
- LOP reduces ESI base only if LOP reduces gross. Confirm via payroll_lookup before answering. [esi:06]
- Overtime counts in ESI base only if tenant maps it as wage. Mapping is configurable. [esi:07]
- Zero ESI case must state reason: over ceiling or excluded. Never invent exemption. [esi:08]
- Correction flow: dry-run diff, cite `[esi:chunk]`, require approval before commit. [esi:09]
- All rates and ceilings are configurable; re-verify per company before quoting numbers. [esi:10]
