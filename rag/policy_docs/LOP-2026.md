# LOP-2026 [lop]

- Per-day salary: `per_day = MONTHLY_BASE / LOP_DIVISOR`. MONTHLY_BASE and LOP_DIVISOR are configurable. [lop:01]
- LOP deduction: `lop = per_day * LOP_DAYS`. LOP_DAYS from biometric CSV via payroll_lookup. [lop:02]
- Payable days: `payable = days_in_month - LOP_DAYS - unpaid_leave`. Leave-type mapping is configurable. [lop:03]
- Leave types `CL/SL/EL/LOP` come from strict LeaveApplyInput; unknown strings escalate to human. [lop:04]
- Half-day rule: `0.5 * per_day` if flagged half-day. Half-day flag source is configurable. [lop:05]
- LOP lowers gross, then PF/ESI/TDS recompute downstream. Order is fixed: attendance -> gross -> deductions. [lop:06]
- "Salary kam ayi" queries: always check LOP_DAYS for that month before blaming TDS. [lop:07]
- Back-dated leave: recompute affected month as dry-run diff, require approval before commit. [lop:08]
- Journal draft must show `gross, lop, net` lines with `[lop:chunk]` citation. [lop:09]
- Divisor, base definition and rounding rule are all configurable per company. [lop:10]
