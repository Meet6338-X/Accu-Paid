# PF-2026 [pf_epfo]

- PF deduction formula: `pf_employee = PF_RATE * PF_WAGE_BASE`. PF_RATE is configurable. [pf_epfo:01]
- PF wage base: `PF_WAGE_BASE = Basic + DA`. Included components are configurable. [pf_epfo:02]
- Employer match formula: `pf_employer = PF_ER_RATE * PF_WAGE_BASE`. PF_ER_RATE is configurable. [pf_epfo:03]
- PF applies only if `monthly PF_WAGE_BASE <= PF_WAGE_CEIL`. PF_WAGE_CEIL is configurable. [pf_epfo:04]
- New joiner with back-dated DOJ: prorate first month by `paid_days / days_in_month`. Divisor rule is configurable. [pf_epfo:05]
- Arrears or overtime paid later attract PF only if mapped to PF_WAGE_BASE. Mapping is configurable. [pf_epfo:06]
- Zero PF case must state reason: below ceiling, excluded component, or exempt flag. Never silently skip. [pf_epfo:07]
- Net-pay impact: `net = gross - pf_employee - tds - esi_employee - lop - other`. Show PF line separately. [pf_epfo:08]
- Correction flow: compute dry-run diff first, cite this doc, require approval before commit. [pf_epfo:09]
- Dispute answer must cite `[pf_epfo:chunk]` and show formula with substituted values. [pf_epfo:10]
